# Slate 0.0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild as one pure-Rust rgpui binary (`slate` 0.0.1) with 5 widgets (terminal, planner, files, browser, orchestration), zero Electron/Chromium/Node in the final binary.

**Architecture:** Vendor PR #54433's wry element into `native/slate-app/src/webview.rs` (proven by `/home/vstaln/wv-spike/src/main.rs`); keep `engine.rs` TerminalManager/ControlServer untouched; replace eframe `ui.rs` bootstrap with an rgpui `RootView`; delete the Electron tree; minimal 0.0.1 rebrand with SLATE_* compat kept.

**Tech Stack:** rgpui 1.3, rgpui-platform 1.3 (x11), wry 0.57, gtk 0.18, raw-window-handle 0.6, portable-pty 0.9, vt100 0.16.2, vte 0.15, serde_json (preserve_order + float_roundtrip), indexmap 2, tokio 1, axum 0.8.

**Spec:** `docs/superpowers/specs/2026-10-02-slate-0.0.1-design.md`

## Global Constraints

- Engine core untouched: `native/slate-app/src/engine.rs` TerminalManager/ControlServer API, journal `preserve_order + float_roundtrip`, `indexmap` insertion order.
- Webview rules from the spike: 400x300 Auto fallback, >1px paint guard, Logical (not Physical) wry bounds, per-id create-once/move-later, gtk::init + build_as_child on the glib-loop child thread, Xcb→Xlib u32 shim.
- Wayland = separate GTK window for 0.0.1 (accepted); X11 = inline `build_as_child`.
- Version floor after Task 1: every version string reads `0.0.1`; `node scripts/check-version.mjs` must print `Version 0.0.1 is consistent.`
- Keep `slate_app` crate name + `SLATE_*` env/socket paths for compat; full rename deferred.
- Branch is `slate-gpui-webview`; never commit on `main` without explicit user consent.
- No new JS runtime in the final binary; `cli/slate.mjs` stays only as a compat shim until the Rust `gray` CLI lands.

Create `native/slate-app/src/shell.rs`:

```rust
use rgpui::*;
use std::sync::atomic::{AtomicUsize, Ordering};

static NEXT_WV_ID: AtomicUsize = AtomicUsize::new(1);

const TABS: [&str; 5] = ["Terminal", "Planner", "Files", "Browser", "Orchestration"];

pub struct RootView {
    focus: FocusHandle,
    active: usize,
    browser_url: String,
    browser_id: usize,
}

impl Focusable for RootView {
    fn focus_handle(&self, _: &App) -> FocusHandle {
        self.focus.clone()
    }
}

impl RootView {
    pub fn new(cx: &mut Context<Self>) -> Self {
        Self {
            focus: cx.focus_handle(),
            active: 0,
            browser_url: "https://example.com".into(),
            browser_id: NEXT_WV_ID.fetch_add(1, Ordering::Relaxed),
        }
    }
}

impl Render for RootView {
    fn render(&mut self, _: &mut Window, cx: &mut Context<Self>) -> impl IntoElement {
        let mut strip = div().h(px(32.)).flex().flex_row().items_center().gap_2().px_2().bg(rgb(0x181825));
        for (i, label) in TABS.iter().enumerate() {
            let mine = i == self.active;
            strip = strip.child(
                div()
                    .id(("slate-tab", i))
                    .px_2()
                    .py_1()
                    .rounded_md()
                    .cursor_pointer()
                    .text_sm()
                    .text_color(if mine { rgb(0xffffff) } else { rgb(0xa6adc8) })
                    .bg(if mine { rgb(0x45475a) } else { rgb(0x00000000) })
                    .child(label.to_string())
                    .on_click(cx.listener(move |this: &mut Self, _, _, cx| {
                        this.active = i;
                        cx.notify();
                    })),
            );
        }
        div().size_full().flex().flex_col().child(strip).child(
            div().flex_1().p_2().text_color(rgb(0xa6adc8)).text_sm().child(
                // Task 4 replaces each string with the real rgpui view.
                text!(match self.active {
                    0 => "Terminal — engine snapshots render here (Task 4)",
                    1 => "Planner — PlannerDocument items render here (Task 4)",
                    2 => "Files — workspace browser renders here (Task 4)",
                    3 => "Browser — wry child renders here (Task 5)",
                    _ => "Orchestration — runs/tasks/dispatches render here (Task 4)",
                }),
            ),
        )
    }
}
```
